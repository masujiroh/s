# 株式会社Liberta Webサイト リニューアル提案（たたき台）

対象サイト：https://www.liberta-kanagawa.com/
デザインカンプ：[`index.html`](./index.html)（ブラウザで開いて確認できます。PC・スマホ両対応）

---

## 1. リニューアルの目的

| 目的 | 内容 |
| --- | --- |
| 信頼感の向上 | 「手作り感」のある見た目から、介護事業所として安心して任せられるプロの印象へ |
| 問い合わせ・見学の増加 | 電話・見学申し込みへの導線を全ページに常設 |
| ケアマネジャー対応 | 定員・対象・営業日などケアマネが知りたい情報をすぐ見つかる位置に |
| 採用強化 | 採用情報への入口をトップに設け、人材確保にもつなげる |

## 2. 現状サイトの課題（想定）

※ 自作サイトでよく見られる点を中心に整理しています。実サイトを見ながら最終確認します。

1. **デザインの統一感** — 文字サイズ・色・余白がページごとにバラつき、全体の印象が素人っぽく見える
2. **情報の階層** — 事業所ごとにページが分かれ、3事業の関係性（通う・暮らす・出かける）が伝わりにくい
3. **行動導線** — 電話番号やお問い合わせボタンが目立たず、スマホからすぐ電話できない
4. **スマホ表示** — 高齢者のご家族はスマホ閲覧が中心。文字の小ささ・タップのしにくさ
5. **情報の鮮度** — 「2023年1月開設予定」など古い記載が残っている
6. **写真** — 施設やスタッフの雰囲気が伝わる写真が少ない／サイズがバラバラ

## 3. デザイン方針

- **トンマナ**：現サイトのモノトーン（チャコール×白×グレー）、太字の「Liberta」ロゴ、キャッチ「自由に生きる」、スタッフ集合写真をそのまま活かす
- **プロらしさを出すポイント**
  - 色はチャコール（#2e2f31）・白・クールグレーに絞り、差し色は写真のスーツの青（#2c6683）を問い合わせボタンだけに使う
  - キャッチ「自由に生きる」は、現サイトの「細いグレーの斜体」＋「極太の黒」の対比を、Webフォント（Noto Sans JP）で再現して精度を上げる
  - 写真に文字を重ねず、壁と同じ色の帯にキャッチを置く（スマホでも顔と文字が重ならない）。スライダーは1枚に絞り、メッセージを明確にする
  - 大きな英字見出し（About / Service など）、細い罫線、直角の要素で、企業サイトらしい端正さを出す
  - 余白を広めに取り、1つのセクションでは1つのメッセージだけを伝える
- **配色はCSS変数で一括管理**（`index.html` 冒頭の `:root`）

5. 事業内容：リハビリ型デイサービス／訪問介護・居宅介護／介護タクシー
6. デイサービス詳細：基本情報・3つの特長・1日の流れ
7. ご利用までの流れ（4ステップ）
8. お知らせ
9. 採用情報バナー
10. 企業概要・アクセス（Googleマップ）
11. お問い合わせ（電話・フォーム）
12. フッター
13. スマホ用 画面下固定ボタン（電話する／見学を申し込む）

## 5. サイトマップ案

1ページ完結型（ページ内リンクで各セクションへ移動）

```
トップ（1ページ）
├─ メインビジュアル「自由に生きる」
├─ About：私たちについて（代表メッセージ）
├─ Service：事業内容（デイサービス／訪問介護・居宅介護／介護タクシー）
├─ Day Service：リハビリ型デイサービス大船西口
│   ├─ 基本情報・3つの特長・1日の流れ
│   ├─ 施設紹介
│   └─ ご利用料金
├─ Flow：ご利用までの流れ
├─ News：お知らせ
├─ Recruit：採用情報 → 採用サイト（jbplt）へリンク
├─ Company：企業概要・アクセス
└─ Contact：お問い合わせ（電話・フォーム）
```
