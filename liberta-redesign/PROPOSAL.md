# 株式会社Liberta Webサイト リニューアル提案（たたき台）

対象サイト：https://www.liberta-kanagawa.com/
デザインカンプ：[`index.html`](./index.html)（ブラウザで開いて確認できます。PC・スマホ両対応）

---

## 1. リニューアルの目的

| 目的 | 内容 |
| --- | --- |
| 信頼感の向上 | 「手作り感」のある見た目から、介護事業所として安心して任せられるプロの印象へ |
| 問い合わせ・見学の増加 | 電話・見学申し込みへの導線を全ページに常設 |
| ケアマネジャー対応 | 提供時間・料金・設備など、ケアマネジャーが知りたい情報をすぐ見つかる位置に |
| サイトの一本化 | 法人サイトとデイサービスのサイトを1つにまとめ、管理しやすくする |
| 採用強化 | 採用情報への入口をトップに設け、人材確保にもつなげる |

## 2. 現状サイトの課題

1. **サイトが2つに分かれている**：法人サイトとデイサービス大船西口のサイトで、ヘッダーのデザイン・フォント・メニューが異なり、同じ会社のサイトに見えにくい
2. **下層ページの情報が少ない**：事業内容はボタン2つ、企業概要は表のみで、ページを移動しても得られる情報が少ない
3. **料金表が画像になっている**：スマホでは文字が小さくて読めず、検索エンジンにも内容が伝わらない
4. **写真の扱い**：写真に文字が直接入っていてスライダーの矢印と重なる。設備紹介では一部の写真が表示されず（ウォーキングマシン・振動マシン・バイク）、配置もばらついている
5. **フォントの混在**：ゴシック・明朝・手書き風が混在し、全体の統一感が出ていない
6. **問い合わせの導線**：電話番号やフォームが目立たず、スマホからすぐに連絡しにくい

## 3. デザイン方針

- **トンマナ**：現サイトのモノトーン（チャコール×白×グレー）、太字の「Liberta」ロゴ、キャッチ「自由に生きる」、スタッフ集合写真をそのまま活かす
- **プロらしさを出すポイント**
  - 色はチャコール（#2e2f31）・白・クールグレーに絞り、差し色は写真のスーツの青（#2c6683）を問い合わせボタンだけに使う
  - キャッチ「自由に生きる」は、現サイトの「細いグレーの斜体」＋「極太の黒」の対比を、Webフォント（Noto Sans JP）で再現して精度を上げる
  - 写真に文字を重ねず、壁と同じ色の帯にキャッチを置く（スマホでも顔と文字が重ならない）。スライダーは1枚に絞り、メッセージを明確にする
  - 大きな英字見出し（About / Service など）、細い罫線、直角の要素で、企業サイトらしい端正さを出す
  - 余白を広めに取り、1つのセクションでは1つのメッセージだけを伝える
- **配色はCSS変数で一括管理**（`index.html` 冒頭の `:root`）

## 4. トップページ構成（カンプの内容）

1. ヘッダー（固定・チャコール）：ロゴ／メニュー／電話番号／お問い合わせボタン
2. メインビジュアル：現サイトのキャッチ「自由に生きる」＋スタッフ集合写真
3. 導入文と強み4点：2施設／大船駅から通いやすい／専門職在籍／送迎あり
4. Libertaに込めた想い（代表メッセージ）
5. 事業内容：デイサービス大船西口／デイサービスAXIS大船
6. 大船西口：基本情報・3つの特長・サービスの流れ・設備紹介・料金表（表はHTMLで作成し、スマホでも読める）
7. AXIS大船：基本情報
8. ご利用までの流れ（4ステップ）
9. お知らせ
10. 採用情報（入職支度金5万円の案内）
11. 企業概要・アクセス（Googleマップ）
12. お問い合わせ（施設ごとの電話番号・メールフォーム）
13. フッター
14. スマホ用 画面下固定ボタン（電話する／見学を申し込む）

## 5. サイトマップ案

1ページ完結型（ページ内リンクで各セクションへ移動）

```
トップ（1ページ）
├─ メインビジュアル「自由に生きる」
├─ About：私たちについて（代表メッセージ）
├─ Service：事業内容（大船西口／AXIS大船）
├─ Ofuna Nishiguchi：リハビリ型デイサービス大船西口
│   ├─ 基本情報・3つの特長・サービスの流れ
│   ├─ 設備紹介（ボディケア／マシンエクササイズ）
│   └─ ご利用料金（加算項目は折りたたみ表示）
├─ AXIS Ofuna：リハビリ型デイサービスAXIS大船
├─ Flow：ご利用までの流れ
├─ News：お知らせ
├─ Recruit：採用情報 → 採用サイト（jbplt）へリンク
├─ Company：企業概要・アクセス
└─ Contact：お問い合わせ（電話一覧・メールフォーム）
```

## 6. あわせてご提案したいこと

- **写真撮影**：施設・設備・スタッフの撮り下ろし（サイトの印象が最も変わるポイント）
- **ロゴの整備**：サイト・名刺・車両で使えるロゴデータの作成
- **お知らせ更新の仕組み**：クライアント様ご自身で簡単に更新できるCMS（現在の制作ツール継続 or WordPress）
- **Googleビジネスプロフィール**の整備で「大船 デイサービス」等の地域検索対策
- デイサービスの**よくある質問**の追加
